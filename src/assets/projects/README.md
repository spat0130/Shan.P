# Project photos

Drop a photo here named after the project's `id` in `src/data/site.js`,
for example `drone-thermal.webp` or `cba-mig.jpg` (webp, jpg, jpeg, png or avif).
It shows up on that project's card automatically. Without a photo, the card
uses a placeholder.

Landscape works best (about 16:10, at least 1200px wide). Add a short
`imageAlt` to the project in `site.js` to describe the photo.
